# Masak Apa Ya

Pengacak menu harian dari bahan yang ada di dapur, dengan animasi Three.js.

**Demo:** https://portofolio-jauza-fawaid.netlify.app/RESEP-MASAK/

![Tampilan Masak Apa Ya](docs/tampilan.jpg)

## Fitur

- Acak menu berdasarkan waktu makan dan bahan
- Resep lengkap dengan bahan dan cara masak
- Latar 3D dengan Three.js

## Menjalankan

Buka `index.html`. Tidak perlu server.

## Teknologi

HTML, CSS, JavaScript, Three.js
